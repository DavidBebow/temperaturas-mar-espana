Metodología. Grados-día anuales calculados sobre la temperatura media diaria. Calefacción (HDD) con base 18 °C: suma anual de máx(0, 18 − Tmedia). Refrigeración (CDD) con la base seleccionada: suma anual de máx(0, Tmedia − base). Datos de reanálisis ERA5 (1960–último año completo) para la capital de cada provincia. El año en curso se excluye por estar incompleto. Fuente de datos: Open-Meteo (archivo ERA5). Elaboración: Calentamiento Global.
